# 配信者育成 MVP

ストリーマー/VTuber 事務所のマネージャーとして、新人配信者を12週間 (または24週間) で育成するシミュレーション。

## 起動
```
node serve.js      # http://localhost:8765
node sim.js 3000 [キャラID|all] [short|long]   # バランス検証 (ボット4種 × 全キャラ。modeは12週=short / 24週=long)
```

## 公開用ビルド
```
node tools/build.js --zip --version=1.0.0    # dist/ と streamer-game-1.0.0.zip を生成
node serve.js dist                           # 生成物をローカルで動作確認 (http://localhost:8765)
```
- `dist/` は `index.html` + `game.js` (core+main結合) + `assets/` (**実素材のみ**) だけ。静的ホスティングにそのまま置けます (file:// 直開きは非対応)。
- 公開版の変更点: 仮素材・未使用ファイル・開発用スクリプト(sim/serve/tools/README)を除外 / 素材スロット画面と説明ボックスを非表示 / 年齢確認(20歳以上)を初回のみ表示 / `noindex` と `rating: adult` の meta を付与 / タイトルにバージョン表示。
- ビルド時の自動検査: 必須スロットの未配置、25MB超のファイル、スロットに対応しないファイル名(綴り間違い)、仮素材や開発用ファイルの混入 (混入は失敗扱い)。
- セーブデータはブラウザの localStorage のみ。外部への通信・解析タグはありません。

## ファイル
- `core.js`  ロジックとデータ (CFG / COMMANDS / EVENTS / CARDS)。UI非依存で node でも動く
- `main.js`  UI と進行
- `sim.js`   ボットによる自動プレイ。数値変更後は必ず回す
- `tools/assets.js` 素材スロットの検出・仮素材生成 / `tools/build.js` 公開ビルド
- `index.html` レイアウトとスタイル

## 調整ポイント (すべて core.js)
- `CFG.targets` ライブの登録者目標 / `CFG.liveScale` ライブ爆発力 / `CFG.legendSubs`
- `INTENS` 強度ごとの倍率と失敗率
- `TANK_TIERS` / `burstChance()` 期待値タンクの段階と炎上確率
- `EVENTS` イベント追加はオブジェクトを足すだけ

## モード
| | 12週 (short) | 24週 (long) |
|---|---|---|
| ライブ | 4・8・12週 (3回) | 4・8・12・16・20・24週 (6回: ミニ配信→オフライン→ホール→全国ツアー→アリーナ→ドーム) |
| 目標登録者 | 1,300 / 4,000 / 9,500 | 1,300 / 3,500 / 7,500 / 13,000 / 21,000 / 32,000 |
| 伝説の卒業 | 14,000人〜 | 60,000人〜 |
| 二人三脚 | 親密度75〜 | 親密度92〜 |
| 専用イベント | - | マンネリの壁・全国ツアーの打診・後輩からの相談 (13週目以降) |

モード設定は `core.js` の `MODES` に集約されています (期間・ライブ週・目標・ライブ規模・エンディング条件)。新しいモードは `MODES` に足すだけです。

## 素材スロット
画像・動画を「スロットkey.拡張子」の名前で `assets/` 以下の**好きなフォルダ**に置き、次を実行するだけで差し込まれます。
```
node tools/assets.js            # manifest更新 + 未配置スロットの仮素材(SVG)生成 + 状況レポート
node tools/assets.js --no-ph    # 仮素材を作らない
node tools/assets.js --clean    # 仮素材を作り直す
```
- 対応形式: 画像 png / webp / jpg / gif / svg、動画 mp4 / webm (動画は自動ループ再生、同名の画像があればポスターに)
- ゲーム内の「素材スロット」画面 (タイトル/メニュー) で配置状況 (✔配置済み ◐仮素材 ✘なし) を確認でき、再読み込みもできます。「スロット名表示」で実素材にkeyを重ねて確認できます。
- 現在 62 スロット。一覧は `core.js` の `listSlots()` が唯一の定義で、イベントやキャラを足すと自動で増えます。

| 種類 | key | 比率 | 備考 |
|---|---|---|---|
| 立ち絵 | `portrait_<キャラID>` | 3:4 | `_good` (調子◎) / `_bad` (不調) の差分は任意。無ければ通常を使用 |
| イベント絵 | `event_<イベントID>` | 16:9 | 任意。無ければ非表示 |
| 特別演出 | `afterparty_accept` など | 16:9 | イベントの選択肢ごと。未配置だと説明ボックスを表示 |
| ライブ演出 | `live_4` / `live_8` / `live_12` | 16:9 | 任意 |
| エンディング | `ending_<キャラID>_<legend/duo/graduate/midway/burnout>` | 16:9 | |

仮素材は `assets/_placeholder/` に生成されます。**公開時は仮素材と未使用ファイルを含めないでください。**
manifest が読めない環境 (HTML を file:// で直接開いた場合など) では `assets/<key>.png` を直接探索する簡易モードで動きます。
